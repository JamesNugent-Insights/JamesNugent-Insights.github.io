Data Transformation

Semi-Structured to Structured Data

Problem

  • Valuable project data existed across individual reports, but its semi-structured format made consolidation and wider analysis difficult.
  • As a result, historical data was largely used only for individual project reporting rather than being reused to inform future projects and decisions.

Solution

  • Worked with users to understand the existing reporting process and identify inconsistencies in how data was recorded across projects.
  • Standardised key fields and categories while retaining the existing source-file format, avoiding additional work or disruption for users.
  • Used advanced Excel formulas to extract and restructure semi-structured data into a consistent intermediate table, accommodating differences in source layouts and removing non-data elements.
  • Built a Power Query transformation process to reshape the data for analysis, including unpivoting, before automatically consolidating data from multiple project files into a single structured dataset.

Impact

  • Created a structured, reusable dataset that provides a foundation for future reporting and analytical solutions.
  • Enabled the development of a historical tender pricing tool, using completed-project data to support more informed and dynamic pricing decisions.
  • Established a clean historical record of completed projects, allowing performance and project outcomes to be analysed retrospectively and used to inform future decisions.
  • Created opportunities for further reporting and analysis, with additional solutions now being explored.
