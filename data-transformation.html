Data Transformation

Semi-Structured to Structured Data

Problem

    • Valuable project data existed across individual reports, but its semi-structured format made consolidation and wider analysis difficult.
    • Data was primarily used during individual projects, with no consolidated historical dataset available to review completed projects or inform future decisions.
    • Additional reporting elements were being manually added to the existing files, creating a cluttered structure and increasing the risk of errors.

    Solution

    • Standardised key fields and categories while retaining the existing source-file format and avoiding disruption for users.
    • Used advanced Excel formulas to restructure semi-structured data into a consistent intermediate table.
    • Used Power Query to reshape and unpivot the data before automatically consolidating multiple project files into a single structured dataset.

    Impact

    • Created a structured, reusable dataset that provides a foundation for future reporting and analysis.
    • Enabled a historical tender pricing tool using completed-project data to support more informed pricing decisions.
    • Established a clean historical record, enabling completed-project performance to inform future decisions and reporting.
